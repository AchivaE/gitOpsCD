# Consul runtime dependency

This is the dedicated Consul sub-module of `helm/platform`. It owns only Consul
so its stateful lifecycle is isolated, while remaining part of the platform
domain and release architecture. The HashiCorp chart is vendored so Argo CD
renders a pinned artifact from Git.

## Security baseline

- TLS, HTTPS-only communication and automatic encryption are mandatory.
- ACL bootstrap and gossip keys are generated by the chart and never committed.
- Persistent server data is enabled in every profile.
- Connect injection and catalog sync remain off until each consuming service has
  an explicit adoption and network-policy design.

## Standard availability profile

This chart is the active Consul implementation for a local Kubernetes cluster.
The standard staging and production overlays deliberately do not reference it:
they use a private external or managed Consul server plane so a Kubernetes
control-plane, CNI, CSI or cluster-upgrade incident cannot also remove service
discovery and configuration availability.

The `values-staging.yaml` and `values-prod.yaml` files are retained only for a
separately approved self-managed Consul-on-Kubernetes deployment. Such a
deployment needs dedicated nodes across availability zones, anti-affinity,
snapshots and a tested restore exercise before it may be used.

## Profiles

`values-local.yaml` uses one persistent server for Minikube only. Staging and
production use three servers. `values-azure.yaml` and `values-aws.yaml` choose
the provider CSI storage class while all other configuration remains portable.

Do not change `global.datacenter`, server count, or bootstrap expectation for a
running datacenter without a Consul migration/runbook and tested backup restore.

## Recovery

Consul intentionally refuses to rejoin from server data that has been offline
longer than its configured rejoin-age limit. For a disposable local datacenter,
the supported recovery is a controlled reset of its **single local** PVC. For
staging and production, recover only from a tested Consul snapshot. The exact
decision tree and safety checks are in
[`CONSUL-RUNTIME-RECOVERY.md`](../../../../../runbooks/CONSUL-RUNTIME-RECOVERY.md).
