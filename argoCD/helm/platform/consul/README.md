# Consul runtime dependency

This is the dedicated Consul sub-module of `helm/platform`. It owns only Consul
so its stateful lifecycle is isolated, while remaining part of the platform
domain and release architecture. The HashiCorp chart is vendored so Argo CD
renders a pinned artifact from Git.

## Security baseline

- TLS, HTTPS-only communication and automatic encryption are mandatory.
- ACL bootstrap and gossip keys are generated by the chart and never committed.
- Persistent server data is enabled in every profile.
- Connect injection and catalog sync remain off until each consuming service has
  an explicit adoption and network-policy design.

## Profiles

`values-local.yaml` uses one persistent server for Minikube only. Staging and
production use three servers. `values-azure.yaml` and `values-aws.yaml` choose
the provider CSI storage class while all other configuration remains portable.

Do not change `global.datacenter`, server count, or bootstrap expectation for a
running datacenter without a Consul migration/runbook and tested backup restore.
